# Plans — archived decision records

Everything in this directory is a dated, closed historical document, kept
verbatim as the record of what was decided and when. Nothing here is
normative: the living charter is [`AGENTS.md`](../../AGENTS.md), whose dated
amendment notes state where each plan's decisions survived, changed, or were
reversed — the 2025 support floor adopted by the 2026-09-21 amendment to the
release plan, for example, was reversed by the 2026-09-27 amendment, and the
architectural review's surviving laws were folded into the charter the same
day it was written. The `archive/` subdirectory holds drafts superseded in
place.

These files are repository history, not consumer documentation; they are
excluded from the published crate (`docs/plans/` in the package `exclude`
list).
