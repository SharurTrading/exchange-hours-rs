# Working tools for the 2022-2024 CME holiday wave (stage 2.2 wave 3).
#
# These are not part of the crate; they reproduce the committed holiday rows
# from the research store's evidence block, and `check_wave3.py` re-derives
# every value it can from the raw artifacts. The committed tables, evidence
# files and tests are the product; these scripts are how they were built.
#
#   python3 tools/wave3_rows.py     # block + raw indexes -> tools/out/*
#   python3 tools/check_wave3.py    # re-runs the generator and re-checks it
#   python3 tools/encode_rows.py    # tools/out/ROWS.json -> the eight modules
#
# `tools/out/` is scratch: it is regenerated by the first command and is not
# committed, because every value that matters lives in the modules and in
# `docs/evidence/`.
